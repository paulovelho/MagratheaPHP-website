# MagratheaPHP2 Benchmark Harness

Reproducible benchmark comparing **MagratheaPHP2**, **Slim 4**, **Laravel 12** and
**Symfony 7** serving JSON API responses.

## What is measured

Two endpoints per framework, no database involved — this measures framework
bootstrap, routing and JSON response overhead only:

- `GET /hello` — minimal JSON response (`{"hello":"world"}`)
- `GET /planets` — a static array of 5 planet objects serialized to JSON

## Environment

- One Docker container per framework, all built from the same `php:8.3-apache`
  image (mod_php), OPcache enabled with `validate_timestamps=0`
- Each container limited to **1 vCPU / 512MB RAM**
- Laravel and Symfony run in production mode with cached config/routes and
  optimized autoloaders; Laravel routes are registered without the `web`
  middleware group (no session/cookies) to keep the comparison fair against
  the API-only micro-frameworks
- Load generated by [`wrk`](https://github.com/wg/wrk) (host binary if
  installed, otherwise via the `williamyeh/wrk` Docker image)
- Per-request peak memory reported by each app via an `X-Peak-Mem` response
  header (`memory_get_peak_usage(false)`)

## Running

```bash
cd benchmark
./run.sh
```

Tunables (env vars): `DURATION` (default `30s`), `WARMUP` (`5s`),
`CONNECTIONS` (`50`), `THREADS` (`2`).

Results are printed and written to `benchmark/results.md` as a Markdown table
(p50/p99 latency, requests/sec, peak memory per request).

Run it 3 times and use the median run. Stop everything afterwards with
`docker compose down`.

## Caveats

- Web server is Apache + mod_php (not Nginx + FPM); all frameworks use the
  identical setup, so relative numbers are comparable
- Numbers depend on the host machine — publish yours together with the
  hardware they were measured on
